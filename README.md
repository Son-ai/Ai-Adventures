Adventure World

Adventure World-ը վեբ հավելված է, որտեղ յուրաքանչյուր օգտատեր կարող է ստեղծել իր սեփական պատմությունը՝ դառնալով դրա գլխավոր հերոսը։

Դու ընտրում ես հերոսին, պատմության միջավայրը, ժանրը և ոճը, նկարագրում այն իրավիճակը, որից պետք է սկսվի արկածը, իսկ Gemini-ի օգնությամբ ստեղծվում է անհատական պատմություն։

Պատմությունը ներկայացվում է էջերի բաժանված գրքի տեսքով։ Կարող ես հերթով կարդալ էջերը, վերադառնալ նախորդ էջին և ցանկացած պահի կրկին բացել արդեն ստեղծած պատմություններդ։

Home – գլխավոր էջ, որտեղից կարող ես սկսել նոր արկած՝ սեղմելով «Start Your Adventure» կոճակը։
Create – այստեղ լրացնում ես հերոսի անունը, ընտրում պատմության աշխարհը, ժանրը, ոճը, նկարագրում սկզբնական տեսարանը և նշում պատմության էջերի քանակը։
My Adventures – քո ստեղծած բոլոր պատմությունների գրադարանը։ Այստեղից կարող ես ընտրել ցանկացած պատմություն և շարունակել ընթերցումը։
Book – պատմության ընթերցման էջը, որտեղ յուրաքանչյուր էջ ցուցադրվում է առանձին։ Էջերի միջև կարող ես անցնել «Previous» և «Next» կոճակներով։

Frontend (client/) – կառուցված է Next.js և React տեխնոլոգիաներով։
Backend (server/) – իրականացված է Python և FastAPI-ի միջոցով։
Gemini API – օգտագործվում է պատմությունների ստեղծման համար։

Գրքերը պահվում են միայն քո browser-ում։ Եթե մաքրես browser-ի տվյալները կամ բացես ուրիշ browser, դրանք չես տեսնի։

Պետք է աշխատեն երկու terminal միաժամանակ։

1. Backend
bash
cd server
cp .env.example .env
# բացիր .env-ը և գրիր քո API key-ը՝ GEMINI_API_KEY=...
uv sync
uv run uvicorn app.main:app --reload

Սերվերը կաշխատի http://localhost:8000-ում։ API-ի փաստաթղթերը՝ http://localhost:8000/docs։

2. Frontend

Նոր terminal-ում՝

bash
cd client
npm install
npm run dev

Կայքը կբացվի http://localhost:3000-ում։
